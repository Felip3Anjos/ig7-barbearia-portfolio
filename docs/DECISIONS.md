# Decisões de produto e engenharia

## Agendamento sem conta
O cliente informa apenas nome e telefone para reduzir atrito.

## Agenda individual
Um horário ocupado por um barbeiro não bloqueia os demais.

## Financeiro
Agendamento não é receita por si só. A receita entra quando o pagamento é registrado.

## Pix
A primeira versão usa QR Code com confirmação manual de recebimento.

## Permissões
A navegação é adaptada ao usuário, mas a autorização real também é validada no backend.

## Dados desta demo
Todos os nomes de clientes e movimentações deste repositório são fictícios.
